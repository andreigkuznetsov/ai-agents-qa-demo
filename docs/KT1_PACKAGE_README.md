# AI Agents QA Demo — пакет КТ1 (DRAFT)

Пакет исходной спецификации для начала разработки согласно утверждённому 12-этапному плану. Основан на принятом UI-прототипе v0.2.

- `docs/01_PROJECT_CHARTER.md` — паспорт и границы проекта
- `docs/02_REQUIREMENTS.md` — требования REQ-001..020
- `docs/03_SCENARIOS.md` — шесть сценариев S01..S06 и оракулы
- `docs/04_ARCHITECTURE.md` — архитектура и режимы
- `docs/05_TEST_STRATEGY.md` — стратегия тестирования AI и оценщиков
- `docs/06_ACCEPTANCE.md` — план КТ1..КТ12 и критерии приёмки
- `docs/07_DECISIONS.md` — вопросы, которые нужно утвердить перед бизнес-логикой
- `prototype/index.html` — принятый UI-прототип v0.2 (симуляция)

**Текущий статус:** КТ1 подготовлена на рассмотрение, **не принята автоматически**. Реальные LLM, backend и БД ещё не реализованы. После утверждения открытых решений: КТ2, локальный каркас FastAPI/PostgreSQL/Docker Compose.
