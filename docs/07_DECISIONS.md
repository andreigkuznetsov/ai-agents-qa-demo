# Реестр открытых решений КТ1

**Назначение:** не допустить появления выдуманных логистических правил и неутверждённых затрат. Варианты ниже — предложения для учебного симулятора; они не описывают правила реальной компании.

| ID | Вопрос | Предложение для учебного стенда | Влияние / статус |
|---|---|---|---|
| DEC-01 | Что считается переносом? | Создаём обращение-заявку; физическая дата доставки не изменяется. | **Требует утверждения**; REQ-002 |
| DEC-02 | Какие состояния заказа блокируют операцию? | Ввести синтетическое `TRANSFER_BLOCKED`, остальные согласовать явным whitelist. | **Требует утверждения**; S01/S03 |
| DEC-03 | Как проверять принадлежность? | Серверный test-auth context, client ID из токена; ID в body не даёт полномочий. | **Требует утверждения**; S06 |
| DEC-04 | Ключ идемпотентности и понятие дубликата? | `(client_id,order_id,requested_date,operation_type)` плюс idempotency key запроса. | **Требует утверждения**; S04/S05 |
| DEC-05 | Timeout и неизвестный исход? | Запросить case по ключу, не повторять запись без подтверждённой идемпотентности. | **Требует утверждения**; S05 |
| DEC-06 | Семантика отказа для чужого ID? | Ответ без сведений о существовании чужого заказа; конкретный HTTP статус выбрать отдельно. | **Требует утверждения**; S06 |
| DEC-07 | Допустимые даты переноса? | Явные delivery-options из API с фиксированной датой `2026-11-26` для примеров. | **Требует утверждения**; S01/S03 |
| DEC-08 | Технология LLM и бюджет? | Provider adapter, сначала ограниченный live-spike; стоимость/провайдер позже. | OPEN для КТ2 |
| DEC-09 | Изоляция запусков? | `run_id`-namespace + транзакционная очистка fixtures; оценить ограничения параллельности. | OPEN для КТ2 |
| DEC-10 | Кто может запускать live в публичном демо? | Только авторизованный владелец; посетителям read-only/replay. | **Требует утверждения** до публичного API |
| DEC-11 | Пороговые значения eval? | Выбирать после получения эталонного набора, но **до** итоговых экспериментов. | OPEN для КТ8/КТ10 |
| DEC-12 | Способ публикации? | GitHub Pages со статическими trace exports; VDS пока не арендовать. | Соответствует согласованному подходу |

**Предлагаемое решение по КТ1:** утвердить DEC-01..07 как правила **синтетического симулятора** либо адресно изменить. DEC-08..11 разрешено оставить открытыми до соответствующих КТ, если они не блокируют работу над архитектурным каркасом.
