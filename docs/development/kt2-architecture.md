Пользователь утвердил Python, FastAPI, PostgreSQL, SQLAlchemy, psycopg, Alembic и Docker Compose. КТ2 выполняется тремя PR. Базовые материалы описаны в [КТ1](../KT1_BASELINE.md). DEC-01–07 сохраняют исходный статус.

| PR | Результат | Проверка |
| --- | --- | --- |
| 1. FastAPI | HTTP-процесс, настройки окружения, liveness, образ и базовый CI | Unit, статические проверки, сборка и запрос к контейнеру |
| 2. PostgreSQL | Compose, миграция, минимальная запись запуска, readiness и совместимый маршрут | Пустая БД мигрирует, данные переживают перезапуск, readiness реагирует на потерю и восстановление БД |

## Запись запуска и изоляция

В MVP используется общая PostgreSQL. Будущие доменные тестовые данные разделяются логически по `run_id`. Изоляция соответствующих сущностей реализуется и проверяется в КТ3/КТ6 после их появления.

| Поле таблицы runs | Контракт |
| --- | --- |
| `run_id` | UUID, первичный ключ |
| `schema_version` | Версия структуры записи |
| `created_at` | Время создания в UTC |
| `status` | Технический статус. В КТ2 достаточно `CREATED` |

Запись проверяется через слой хранения с синтетическими данными. Поля несуществующих запусков модели, расходы, токены, промпты и результаты оценки в КТ2 не заполняются.

## HTTP и запуск

- PR 1 вводит `GET /health/live` с ответом `200 {"status":"ok"}`. Маршрут проверяет доступность процесса без обращения к БД.
- PR 2 вводит `GET /health/ready` и совместимый `GET /healthz`. Оба проверяют доступность PostgreSQL и ожидаемую ревизию схемы. При недоступности возвращается `503` без внутренних подробностей. Liveness продолжает отвечать.
- В Compose одноразовый сервис миграций должен завершиться успешно до старта API. PostgreSQL доступна только внутри сети Compose. Том сохраняется при обычной остановке. Хостовый HTTP-порт по умолчанию публикуется на loopback.
- Секреты передаются окружением, без попадания в Git или логи. Бизнес-маршруты, агенты, работа с реальными пользовательскими данными и внешние LLM не входят в КТ2.
- Параметры соединения, пула и тайм-аутов PostgreSQL выбираются и обосновываются в PR 2, где их можно проверить.

## Параметры PR 1

Python 3.13.18 выбран для одинаковой версии в контейнере и при локальном запуске. Приложение использует минимальные пакеты FastAPI и Uvicorn. Uvicorn запускается с одним worker и принимает `UVICORN_HOST`, `UVICORN_PORT` и `UVICORN_LOG_LEVEL`. По умолчанию локальный процесс слушает `127.0.0.1:8000`. Внутри контейнера он слушает `0.0.0.0:8000`, а команда публикации порта ограничивает доступ на хосте адресом `127.0.0.1`.

Версии прямых зависимостей заданы в `backend/pyproject.toml`, полный граф с контрольными суммами закреплён в `backend/uv.lock`. Установка использует `uv sync --locked`. Образы Python и uv зафиксированы по digest в Dockerfile. Базовые проверки в CI выполняются из отдельной стадии образа. Финальная стадия содержит только зависимости запуска и выполняется от непривилегированного пользователя.
