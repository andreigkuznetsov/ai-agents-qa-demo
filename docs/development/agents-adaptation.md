# Адаптация правил работы

| Категория | Изменения относительно исходного AGENTS.md |
| --- | --- |
| Сохранено | Один PR на задачу, несколько PR на Issue, границы и приёмка, отдельные ветки и worktree, проверка базы и сохранение локальных изменений. Связь PR–Issue через Development, разрешение на merge и закрытие, независимое ревью точного SHA и повторная проверка. Периодический, досрочный и релизный аудит. Обновление документации с кодом и защита пользовательских файлов. |
| Адаптировано | Прямой коммит в main ограничен отдельно разрешённой минимальной инициализацией. Процедуры ревью и аудита вынесены отдельно. Временные файлы привязаны к каталогу задачи с проверкой путей и согласованной очисткой. |
| Исключено | Требования, документы и пути прежнего репозитория, правила исследования внешнего интерфейса и работы с его сообщениями, широкое исключение для прямых коммитов в main. |
| Добавлено | Защита базовой линии КТ1, сценариев S01–S06 и эталона v0.2. Ссылки PR на REQ-XXX. Разделение AI-компонентов и изоляция эталонов, приоритет детерминированных проверок, воспроизводимость, отдельная маркировка replay и live, лимиты live и защита операций с БД. |
