# Системный аудит

При подготовке PR и перед его слиянием сверь актуальную базу и [журнал аудитов](audit-log.md). Найди слитые PR после последнего завершённого системного аудита или с начала истории. Считай PR по фактическому diff. PR только с документацией не учитываются. Запиши в описание PR точку отсчёта, список учтённых PR, их число и срок аудита.

После пятого учитываемого слияния заверши аудит до следующего этапа разработки. Исправления по итогам аудита продолжают проходить независимое ревью. Помимо досрочных оснований в [AGENTS.md](../../AGENTS.md) проведи аудит при завершении крупного модуля.

Независимость и фиксация доказательств следуют [процессу ревью](review-process.md). Системный аудит охватывает взаимодействие компонентов, согласованность контрактов и данных, накопленные изменения. Ревью одного PR не заменяет системный аудит.

В журнале укажи дату, основание, полный SHA, учитываемые PR, охват, проверяющего, результаты, ограничения и ссылку на отчёт. Блокирующие замечания устрани и перепроверь до дальнейшего развития затронутой части. Остальные зафиксируй с приоритетом. План аудита не меняет точку отсчёта.
